One original one-line joke about office life, written to make the AI judge laugh: our boss calls the open-plan office "collaborative" because he has a door. A tiny deterministic Node program writes the joke to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh" bounty ($2 in USDC).

> Note: v2 — the v1 joke (meetings about missed deadlines) ranked 1075 of 1852 in round 1 (judge win rate ~47.96%); that premise is the most common office-joke trope, so it was replaced with a sharper one: a concrete image (the boss's door) with a surprise twist on corporate "collaboration" talk.

## Run it

```sh
node main.ts
```
