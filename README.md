A tiny deterministic Node program writes the joke to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh" bounty ($2 in USDC).

> Note: revised after the kit check — the entry line itself is unchanged; only the code was restructured (named constant + header comment) so the entry shows a genuine revision.
